## Deviations (approved-awaiting: build-forced detail)
- **Empty SHARED lib is not allowed by CMake** → libraries are built from a
  common OBJECT lib seeded with `src/abi/version.cpp` (exported
  `opencode_abi_version` symbol). The header's static-inline twin remains the
  header-only default (`OPENCODE_ABI_HEADER_ONLY` guard). Minor early ABI symbol,
  reversible at Phase 12. Logged in NOTES.md.
- **android preset** not built in CI yet (NDK installs are a Phase 12 concern);
  the toolchain stub exists and configures once `ANDROID_NDK` is provided.
- Local machine cannot run ASan (proot sandbox blocks shadow-memory mmap) and
  cannot build on the fuse-mounted /sdcard (CMake reconfigure loop). Neither
  affects CI; both logged in NOTES.md.
