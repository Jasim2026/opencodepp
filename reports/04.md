# CHECKPOINT 04 — PASS

**Phase:** 04 Networking (socket, tls, http1, sse, pool, policy, offline, drill).

## What was done
- **Transport** (`src/net/socket.{h,cpp}`, `tls.{h,cpp}`, `tls_host.{h,cpp}`,
  `tls_mbedtls.{h,cpp}`, `transport.{h,cpp}`): non-blocking sockets driven by
  `core::EventLoop` (blocking-over-loop, absolute monotonic deadlines), DNS via
  `getaddrinfo`, IPv4/IPv6, TCP connect with EINPROGRESS handling. `TlsSession`
  (opaque, move-only, adopt/release) + `TlsBackend` interface with two
  backends: host-callback (always compiled) and mbedTLS (only under
  `OPENCODE_USE_MBEDTLS=ON`; `tls.cpp` dispatches via `#if OPENCODE_USE_MBEDTLS`).
  `Transport` = connected fd + optional TLS session + loop-aware blocking
  `read`/`write`/`close`.
- **HTTP/1.1** (`src/net/http1.{h,cpp}`): request builder (`http_build_request`,
  X-Request-Id idempotency key), incremental `HttpParser` (head, content-length,
  chunked, EOF-framed bodies), `http_drain_body` (premature-EOF = retryable
  `e_net_connect`), `http_status_error` (429→e_rate_limit, 401/403→e_auth,
  other 4xx/5xx→e_provider_err), `http_exchange` (one-shot, optional response
  cap with `truncated` flag).
- **SSE/JSONL** (`src/net/sse.{h,cpp}`): `SseParser` (event frames, 4 MiB
  frame cap, abort flag, event-count cap) + `sse_stream` (collect to memory).
- **Retry policy** (`src/net/policy.{h,cpp}`): deterministic xorshift jitter;
  base 300 ms ×2, ±30%, cap 30 s, maxRetries 8; `decide(ec, attempt)` and
  `decide_retry_after(retry_after_s, attempt)`; retryability from
  `core::retry_class` (429/5xx/net-* retryable; `e_proto_parse`/`e_auth` not).
- **Connection pool** (`src/net/pool.{h,cpp}`): per-host idle keep-alive reuse
  (fd-preserving), per-host idle + in-flight caps, age reaping, unhealthy
  transport close, injectable `Opener` (default `open_transport`).
- **Offline queue + meter** (`src/net/offline.{h,cpp}`, `meter.{h,cpp}`):
  connectivity probe → `online`/`offline`/`recovering` state machine with a
  callback; bounded FIFO queue (never drops; `e_net_overflow` at capacity);
  submit-when-online vs enqueue-when-offline; FIFO drain on recovery with
  requeue-at-head on failure. `Meter`: atomic counters (bytes/tokens in+out,
  retries, reconnects, round-trips, timeouts, offline_ms) + capped rtt histogram
  (p50/p95) for the Phase 5+ provider and Phase 13 metrics surface.
- **Drill** (`tools/drill.cpp`): 7-scenario fault-injection battery with an
  in-process programmable mock (ok / 429+Retry-After / 500 / truncate /
  garbage) driving the real net layers. `tools/mock_api.cpp` gained
  `--scenario ok|rate_limit|server_error|truncate|garbage` for manual/CI use.
- **Wiring**: net sources into `opencodepp_core`, 4 net tests + drill into
  CTest, `mbedtls` CMake preset (dev + `OPENCODE_USE_MBEDTLS=ON` +
  `target_compile_definitions(opencodepp_core PUBLIC OPENCODE_USE_MBEDTLS=1)`),
  and a `net-tls` CI job mirroring the store-sqlite job.

## Deviations
- **`tools/drill` is self-contained, not a proxy** (05 §7 described a proxy
  sitting between engine and API): it runs an in-process programmable mock and
  drives the net layers directly. Deterministic, no process management,
  ctest-friendly; `mock_api --scenario` still gives the standalone fault
  fixture the plan wanted.
- **`RetryBudget.time_cap_ms` is parsed but not enforced** by `decide()`: the
  overall attempt-window check belongs to the Phase 10 agent retry loop.
- **mbedTLS session capture uses the portable 2-arg
  `mbedtls_ssl_get_session`** (the 3.x-only `mbedtls_ssl_session_copy` does not
  exist even in 3.6.5; CI's 2.28 caught the original inverted guard). The
  `mbedtls_pk_parse_key` 5/7-arg split IS version-guarded (2.x vs 3.x).
- **`OPENCODE_USE_MBEDTLS` must be a compile definition**, not just a source
  selector: `tls.cpp` dispatches on it. Added via
  `target_compile_definitions(opencodepp_core PUBLIC OPENCODE_USE_MBEDTLS=1)`.
- **Blocking-over-loop everywhere**: no hidden threads in the library (pool
  acquire waits on the caller's loop up to `acquire_wait_ms`; drills/tests use
  their own server threads). Consistent with the no-hidden-threads rule.
- No ASan locally (proot limitation, see NOTES.md); CI is the sanitizer site.

## Decisions for later phases
- `http_exchange`/`http_drain_body`/`sse_stream` + `Meter` are the Phase 5
  provider primitives; `RetryPolicy` is the Phase 6 retry budget core; the
  `OfflineQueue` state machine is the Phase 10 `WaitingForNetwork` input;
  `Pool` is shared by providers and (later) the agent loop.
- Error mapping is fixed now: 429→e_rate_limit, 401/403→e_auth, 4xx/5xx→
  e_provider_err, premature-EOF→e_net_connect (retryable), parse→e_proto_parse
  (non-retryable). Providers must not re-derive their own mapping.
