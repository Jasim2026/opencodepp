## What was done

Five commits, matching the plan's definition of done:

1. **`e668104` perf(hardening): T2 measurement gate + CLI `--version`**
   — `tools/measure.cpp` + `tools/measure_common.h` (in-process latency/RSS
   micro-benchmarks with a 5x-slack hardening gate, JSON report →
   `reports/*_measure.json`, glibc-conditional `malloc_trim`,
   `rss_kb_min()` = min-of-3 samples with 10 ms sleeps), `hardening` ctest
   (repo-root cwd, size-limit 15 MB on `-Os` builds else 0 = informational),
   `opencode_cli --version`/`-v`, additive `OPENCODE_VERSION_{MAJOR,MINOR,
   PATCH}` (0.13.0), `OUTPUT_NAME opencodepp_cli`, CI version-smoke step.
2. **`4eb22f8` test(fuzz): deterministic cross-module fuzz sweep**
   — `tests/fuzz_test.cpp` (seedable `--seed`/`--iters`): codec hostile
   bytes + byte flips + canonical re-encode equality, SSE random chunking,
   JSON parse/re-dump idempotence, intent classifier + token-estimator
   bounds, verify gate stop-on-first-failing-stage invariant; `fuzz_test`
   (defaults 500 iters) + `fuzz_test_extra` (seed 7, 300 iters) ctests;
   `tools/bench_profile.h` shared inline benchs + `bench_engine --profile`;
   `tools/measure.cpp` refactored onto `bench_profile.h`; CI `fuzz` job
   (5 seeds × 1000 iters under ASan).
3. **`1d5afd3` test(soak): long-run resilience driver + fault injection**
   — `run_agent --fault 1|2|3` (HTTP 500 / truncated SSE chunk / malformed
   SSE frame, injected on request 0 then success on retry) + mock
   `--prompt`; `tools/soak.cpp` (forks the real `run_agent --mock`, scripted
   task prompts, per-task watchdog with SIGKILL on hang, 100 ms child RSS
   polls, faults every K tasks, zero-abort/zero-hang/RSS-growth gate);
   `soak_short` + `run_agent_fault` ctests; CI `soak` job (24 tasks).
4. **`c0830f7` fix(soak): steady-state RSS across tasks** — the first soak
   CI run flagged "UNBOUNDED GROWTH" (50+ MB) on every ASan build because
   the min sample was taken before ASan shadow memory is touched. Each task
   is a fresh process, so the meaningful leak signal is the end-of-task RSS
   footprint across tasks, not intra-run min/max; slack 20 MB.
5. **`4f66902` fix(git probes): retry transient git failures once, 10 s
   timeout** — release-only `tools_test` flake: `git.diff` hit the 5 s
   subprocess timeout under parallel ctest load. Read-only probes retry once
   and double the window; real failures still surface.

## Deviations / decisions

- ASan dev binaries exceed the 15 MB budget → binary-size assertion enforced
  only when `--size-limit > 0`; CMake sets 15 on `-Os` builds, 0 otherwise.
- `hardening` asserts at 5x slack to keep the CI gate stable across runners.
- Soak gates on steady-state cross-task RSS (fresh process per task) instead
  of intra-run min/max, which is ASan instrumentation noise.
- `git_run` probe hardened (one retry, 10 s) after a release-only flake;
  correctness preserved (non-git dirs still fail).
