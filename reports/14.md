## Deviations / decisions

- The plan's `21_CHECKPOINT_TRACKER.md` maps to the repo's live
  `CHECKPOINTS.md` (rows 00–14, all `done`); Phase 14 close-out lives here.
- The acceptance gate's `python3 tools/measure > final_measure.json` is
  aspirational: `tools/measure` is a native binary (stdlib-only) — the
  equivalent is `tools/measure --out reports/final_measure.json`, which is
  what CI's `hardening` ctest asserts.
- The Android example is source-only: the JNI glue path is CI-verified via
  `bindings/jni` (JDK job); the NDK build happens out-of-tree (documented in
  `examples/android/README.md`).
- pkg-config files are relocatable (prefix derived from `pcfiledir`) because
  `cmake --install --prefix` overrides the configured prefix; the naive
  `prefix=/usr/local` form would break every `--prefix` install.
- `Threads::Threads` is a PUBLIC link requirement (engine backoff uses
  `std::thread`); the package config calls `find_dependency(Threads)` so the
  installed static lib links on any libc, not just glibc ≥ 2.34.
